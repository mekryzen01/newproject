# ระบบบริหารจัดการวัดและศาสนพิธี (Temple Management & Rituals System)
### วัดศรีสว่างธรรมาราม

ระบบแอปพลิเคชันเว็บแบบครบวงจรสำหรับวัดและศาสนพิธี พัฒนาขึ้นโดยใช้เฟรมเวิร์ก **Next.js (App Router)** ร่วมกับ **Supabase** และระบบฐานข้อมูล **Postgres (Drizzle ORM)** ออกแบบและตกแต่งภายใต้สถาปัตยกรรมดีไซน์หรูหราพรีเมียม (Curated Aesthetic) ใช้งานง่าย รองรับภาษาไทยและระบบปฏิทินไทย-ล้านนาอย่างสมบูรณ์แบบ

---

## 🌟 ฟีเจอร์หลักของระบบ (Main Features)

### 1. ระบบทะเบียนพระภิกษุสามเณร (Monks Management)
*   ระบบจัดเก็บประวัติพระภิกษุและสามเณรที่จำพรรษาในวัด
*   รองรับการแสดงผล 2 รูปแบบ: **Grid View** (การ์ดรูปภาพสวยงาม) และ **Table View** (ตารางสแกนข้อมูลสะดวกรวดเร็ว) พร้อมปุ่มสลับมุมมอง
*   จัดการเพิ่ม แก้ไข ลบ และสืบค้นข้อมูลได้อย่างมีประสิทธิภาพ

### 2. ระบบตารางงานนิมนต์และศาสนพิธี (Ritual & Schedule Management)
*   จัดตารางงานนิมนต์ประจำวัน ปฏิทินงานวัด และกิจนิมนต์ภายนอก
*   ระบุเวลา สถานที่ เจ้าภาพ และจำนวนพระภิกษุที่ต้องการจัดสรร
*   **ระบบตรวจสอบสิทธิ์ป้องกัน "วันเก้ากอง" (Lanna Astrology Validation):** บล็อกการบันทึกพิธีหรือชื่องานที่เกี่ยวข้องกับการฌาปนกิจ/เผาศพ หากวันที่เลือกตรงกับ "วันเก้ากอง" ตามประเพณีล้านนาโบราณ

### 3. ระบบจองศาลาบำเพ็ญกุศลและกิจกรรม (Sala Booking System)
*   ระบบบริหารจัดการศาลาวัด แยกตามระดับและประเภทการใช้สอย
*   ปฏิทินจองศาลาแบบ Interactive แสดงสถานะการจองตามสีประเภทกิจกรรม (เช่น งานศพ, งานแต่งงาน, งานบุญพิธี)
*   **แจ้งเตือนวันเก้ากองกะพริบอัตโนมัติ:** เมื่อคลิกดูวันเก้ากองในระบบปฏิทิน จะมีแถบเตือนสีแดงกะพริบแจ้งทันที
*   **ระบบป้องกันการจองวันสุดท้ายตรงกับวันเก้ากอง:** หากเลือกจัดงานศพ และวันสุดท้ายของการจอง (วันฌาปนกิจศพ) ตรงกับวันเก้ากอง ระบบจะแสดงหน้าต่างเตือนและปฏิเสธการจองทันทีเพื่อรักษาจารีตประเพณีล้านนาโบราณ
*   **LINE OA Integration:** ส่งข้อความแจ้งเตือนรายละเอียดการจองศาลาเข้าสู่ LINE OA ของวัดโดยตรงผ่านระบบ Server Route Proxying ไปยัง PHP Endpoint

### 4. ระบบทะเบียนจัดตั้งศพและฌาปนกิจ (Funeral Arrangements Registry)
*   ระบบลงทะเบียนประวัติผู้วายชนม์การฌาปนกิจครบวงจร เชื่อมโยงจากการจองศาลาต้นทาง
*   **ฟอร์มลงทะเบียนตรงตามใบจดแจ้งจริง:** ปรับปรุงโครงสร้างตารางข้อมูลและหน้าฟอร์มให้สามารถบันทึกรายละเอียดได้ครบถ้วนเทียบเท่าใบจดแจ้งกระดาษจริงของวัด (เช่น เลขประจำตัวประชาชน สัญชาติ อาชีพ ประวัติการเสียชีวิต ข้อมูลผู้แจ้ง และส่วนเฉพาะของเจ้าหน้าที่อย่างจำนวนคืนสวดอภิธรรม)
*   **Deceased Photo Uploader:** รองรับการอัปโหลดไฟล์รูปภาพผู้วายชนม์, ใบเสร็จรับเงิน และใบมรณบัตร เข้า Google Drive โดยตรง
*   **DataTable คุมธีมสีทอง:** ตารางรายการมาพร้อมกับระบบค้นหา, เลือกจำนวนรายการต่อหน้า (Page Size Selector), ปุ่มควบคุมหน้าแสดงผล (Pagination), และปุ่มคลิกเรียงลำดับหัวข้อคอลัมน์ (Sorting)
*   **Modal Sizing XL (`max-w-4xl`):** หน้าต่างกรอกประวัติสัดส่วนสมมาตร ไม่ล้นหน้าจอ

### 5. ระบบคลังครุภัณฑ์วัดและการยืม-คืน (Inventory & Borrowing System)
*   จัดเก็บและดูแลครุภัณฑ์วัด (เช่น เต็นท์, โต๊ะ, เก้าอี้, ถ้วยชาม, พัดลม)
*   **Google Drive Photo Storage:** เก็บไฟล์ภาพครุภัณฑ์แต่ละชิ้นไว้บน Google Drive จริงอย่างไร้รอยต่อ ป้องกันปัญหาพื้นที่โฮสต์เต็ม
*   ระบบทำรายการ ยืม-คืนสิ่งของ สำหรับชุมชนรอบวัด พร้อมบันทึกเบอร์โทรศัพท์และกำหนดส่งคืน

### 6. ระบบการเงินและบัญชีวัด (Finance & Bookkeeping)
*   บันทึกรายรับ-รายจ่ายของวัด (เงินทำบุญ, ค่าน้ำไฟ, ค่าบูรณปฏิสังขรณ์)
*   **Financial Analytics Dashboard:** แสดงสัดส่วนรายรับแยกตามตู้บริจาค/วัตถุประสงค์ และสัดส่วนรายจ่ายแยกตามหมวดหมู่ด้วยวิชวลกราฟแท่ง (Visual Bar Charts) มีการวิเคราะห์เปอร์เซ็นต์แบบเรียลไทม์
*   **ระบบจัดการค่าใช้จ่ายประจำรายเดือน (Recurring Expenses):** กำหนดเทมเพลตค่าใช้จ่ายประจำ (เช่น ค่าเน็ต, ค่าจ้าง) พร้อมฟังก์ชันคีย์รายจ่ายประจำเดือนพร้อมกันหลายรายการ (Batch Posting)
*   **ระบบแจ้งเตือนเตือนภัยล่วงหน้า 3 วัน (3-Day Automated LINE Warning):** ตรวจสอบวันกำหนดชำระรายจ่ายประจำล่วงหน้า 3 วัน และส่งการแจ้งเตือนเข้ากลุ่มไลน์หลักของวัดโดยอัตโนมัติผ่าน Cron API (`/api/cron/check-recurring-expenses`)
*   **ระบบส่งการเตือนส่วนบุคคล (Assigned Payer Direct Alert):** ยิงแชทแจ้งเตือนส่วนตัว (LINE Push Message) ถึงพระภิกษุหรือผู้รับผิดชอบรายการนั้นโดยตรง
*   **Payment Status Checklist:** ระบบตรวจสอบสถานะชำระจริง (⏳ รอโอนจ่าย / ✅ ชำระแล้ว / 🟢 รับเข้าแล้ว) พร้อมปุ่มคลิก "ยืนยันชำระแล้ว" บนตารางรายการได้ทันที
*   **ระบบสำรองข้อมูลวัดอัตโนมัติ (Automated System & Database Backup):** ส่งออกข้อมูลธุรกรรม บัญชี และงานนิมนต์เป็นไฟล์ JSON พร้อมแจ้งเตือนเข้ากลุ่มไลน์ผ่าน `/api/cron/backup`

### 7. ระบบจัดการสิทธิ์การเข้าถึงแบบจำแนกบทบาท (Granular Role-Based Access Control - RBAC)
*   **🔴 Admin / 🟠 Abbot (ผู้ดูแลระบบ & เจ้าอาวาส):** สิทธิ์ควบคุมและบริหารจัดการเต็ม 100% พร้อมหน้าต่าง Executive Dashboard และปุ่มสำรองข้อมูลระบบด่วน
*   **🔵 Editor (ผู้แก้ไขข้อมูล):** สิทธิ์บันทึกและแก้ไขข้อมูลรายรับ/รายจ่าย จัดการหมวดหมู่การเงิน ไม่เห็นเมนูตั้งค่าผู้ใช้งาน
*   **🟢 Staff (เจ้าหน้าที่วัด):** สิทธิ์คีย์บันทึกรายรับจากตู้ทำบุญ โดยระบบจะซ่อนกราฟสรุปยอดเงินทุนสุทธิเพื่อความปลอดภัย
*   **🟡 Member (พระภิกษุ-สามเณรทั่วไป):** เข้าถึงตารางงานนิมนต์ส่วนตัวและบัญชีส่วนตัวของตนเองโดยตรง
*   **API Query Optimization:** ปรับปรุงระบบ Layout Notification จากเดิมที่ดึงข้อมูล Supabase บนทุกหน้าที่มีการเปลี่ยนเส้นทาง ให้ดึงข้อมูลเมื่อเปิดใช้งาน และสืบค้นเบื้องหลัง (Background Polling) ทุก 3 นาทีแทน เพื่อลดความถี่การร้องขอ API ลงกว่า 80%
*   **Dynamic Address Loader (Code-Splitting Optimization):** ปรับปรุงระบบเลือก จังหวัด-อำเภอ-ตำบล (ThaiAddressSelect) ให้ดึงข้อมูลภูมิศาสตร์ไทยแบบขนาน (Lazy Dynamic Import) เมื่อคอมโพเนนต์ถูกเปิดใช้งานเท่านั้น ช่วยลดขนาด Javascript Bundle แรกเริ่มของระบบลงอย่างเห็นได้ชัด

### 8. การปรับแต่งภาษาและองค์ประกอบเสริม (System Customization)
*   **Thai DatePicker ทั้งระบบ:** ปรับเปลี่ยนคอมโพเนนต์เลือกวันที่เป็นแบบปีพุทธศักราช (พ.ศ.) และเดือนภาษาไทย 100%
*   **Menu Permission Control:** ระบบการจัดการสิทธิ์ของเมนูและลิงก์ต่าง ๆ บน Dashboard ตามกลุ่มผู้ใช้ (เช่น พระสังฆาธิการ, พระลูกวัด, ผู้ดูแลระบบ, มัคนายก)

### 9. ระบบรายงานและวิเคราะห์ (Reports & Analytics Dashboard)
*   **รายงานการจองศาลาและงานฌาปนกิจ:** แสดงสถิติยอดจองศาลาสะสม, จำนวนจัดตั้งศพที่สมบูรณ์/ไม่ครบถ้วน พร้อมกราฟแท่ง (Bar Chart) ย้อนหลัง 6 เดือน
*   **รายงานรายรับ-รายจ่ายของวัด:** สรุปยอดรายรับ, รายจ่าย และเงินคงเหลือสุทธิ แสดงกราฟแท่งคู่ (Double Bar Chart) เปรียบเทียบเดือนต่อเดือน
*   **รายงานการยืม-คืนครุภัณฑ์:** แสดงสัดส่วนสถานะคืนแล้ว/กำลังยืม/เกินกำหนด ด้วยกราฟ Horizontal Stacked Bar พร้อมตารางข้อมูลค้างส่งคืน
*   **รายงานทะเบียนฝากอัฐิ:** สถิติปริมาณการฝากอัฐิสะสมและรายการใหม่ภายใน 7 วัน แสดงกราฟเส้น (Line Chart) รายเดือน
*   **ส่งออกข้อมูล:**
    *   **Export Excel (CSV):** ส่งออกข้อมูลดิบทุกรายงานเป็นไฟล์ CSV รองรับภาษาไทย (UTF-8 BOM)
    *   **โหลดรูปกราฟ (PNG):** แปลงกราฟ SVG เป็นภาพ PNG ความละเอียดสูง (800×400px) ดาวน์โหลดได้ทันที
    *   **พิมพ์รายงาน (PDF):** ใช้ `window.print()` พร้อมจัดรูปแบบ Print-friendly ซ่อนปุ่มควบคุม แสดงหัวกระดาษวัดอัตโนมัติ

### 10. ระบบการทำงานแบบออฟไลน์และแอปพลิเคชันมือถือ (Offline Mode & PWA Capabilities)
*   **Progressive Web App (PWA Support):** ติดตั้งไฟล์ `manifest.json` และ Service Worker (`sw.js`) ทำให้ผู้ใช้งานสามารถกด **"Add to Home Screen"** บนสมาร์ตโฟนหรือแท็บเล็ตเพื่อใช้งานแอปวัดได้เสมือนแอปพลิเคชันจริง
*   **Offline Shell & Cache:** แคชหน้าเว็บและทรัพยากร static ทั้งหมดไว้ในเครื่อง ทำให้พระภิกษุสามเณรสามารถเปิดดู **ตารางงานนิมนต์ส่วนตัว** และสถานที่นิมนต์ได้แม้อยู่ในพื้นที่อับสัญญาณอินเทอร์เน็ต
*   **Auto Offline Sync Queue (`lib/offlineSync.ts`):** หากสัญญานอินเทอร์เน็ตขัดข้องขณะกำลังกรอกข้อมูล (เช่น ทะเบียนจัดตั้งศพ, บันทึกการเงิน, ตารางนิมนต์) เมื่อกด "บันทึก" ระบบจะไม่แสดงข้อความผิดพลาด แต่จะเข้าสู่โหมดออฟไลน์อัตโนมัติ พร้อมแสดงป้ายเตือน *"บันทึกออฟไลน์แล้ว 📶 ข้อมูลถูกเก็บบันทึกไว้ในเครื่องแล้ว และจะทำการซิงค์อัปเดตให้อัตโนมัติเมื่อเน็ตกลับมา"* และทำการ **ซิงค์ข้อมูล (Auto-Sync) กลับขึ้นฐานข้อมูล Supabase ทันทีที่เชื่อมต่อเน็ตได้อีกครั้ง**

### 11. ระบบจัดคิวเวรปฏิบัติกิจสงฆ์ประจำวัน (Daily Monk Duty Schedule)
*   **Auto-Rotate Duty Engine:** ระบบสุ่มกระจายจัดคิวเวรหมุนเวียนอัตโนมัติ (กวาดลานวัด, ทำความสะอาดพระอุโบสถ, ดูแลตู้บริจาค, จัดเตรียมหอฉัน, ตรวจความเรียบร้อย) ให้แก่พระภิกษุสามเณรที่จำพรรษาอย่างเท่าเทียมกัน
*   **Personal Duty Highlights:** แถบแสดงรายการเวรประจำวันที่พระภิกษุรูปนั้นได้รับมอบหมายบนหน้าแดชบอร์ดส่วนตัว พร้อมปุ่มคลิกทวนสถานะ *"✅ ปฏิบัติเรียบร้อยแล้ว"*
*   **Role-Based Management:** เจ้าอาวาสและผู้ดูแลระบบควบคุมการจัดคิวเต็มรูปแบบ สมาชิกทั่วไปดูคิวและกดทวนสถานะได้

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

*   **Front-end Framework:** Next.js (TypeScript, React 19)
*   **Styling:** Tailwind CSS & Vanilla CSS (Curated Amber-Gold Theme)
*   **Icons:** Lucide React
*   **Database:** Supabase (Postgres)
*   **ORM:** Drizzle ORM
*   **API & Integrations:** 
    *   Google APIs Client Library (`googleapis`) สำหรับเชื่อมต่อ Google Drive
    *   LINE Messaging API สำหรับระบบส่งการแจ้งเตือน

## 📦 การติดตั้งและเริ่มต้นใช้งาน (Installation & Setup)

### 1. โคลนโปรเจกต์และติดตั้ง Dependency
ดาวน์โหลดซอร์สโค้ดของโครงการลงในเครื่องคอมพิวเตอร์ของคุณ จากนั้นใช้คำสั่งด้านล่างนี้เพื่อติดตั้งแพ็กเกจที่จำเป็น:

```bash
# ติดตั้ง dependencies ผ่าน npm
npm install

# หรือหากใช้ bun
bun install
```

### 2. ตั้งค่าไฟล์ Environment Variables
คัดลอกไฟล์ต้นแบบ `.env.local.example` เป็น `.env.local`
```bash
cp .env.local.example .env.local
```
เปิดไฟล์ `.env.local` และกำหนดค่าต่าง ๆ ดังนี้:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key

# ตัวเลือกเสริมสำหรับการอัปโหลดรูปภาพไปยัง Google Drive
# GOOGLE_SERVICE_ACCOUNT_EMAIL=...
# GOOGLE_PRIVATE_KEY=...
# GOOGLE_DRIVE_FOLDER_ID=...

# ตัวเลือกเสริมสำหรับการเชื่อมต่อแจ้งเตือน LINE OA
# LINE_CHANNEL_ACCESS_TOKEN=...
```

## 📖 คู่มือการใช้งานระบบปฏิทินและข้อห้าม "วันเก้ากอง" ล้านนา

ระบบได้รับการออกแบบให้คำนวณ **วันดี-วันเสีย** โดยเฉพาะ **"วันเก้ากอง"** (วันห้ามเผาศพตามตำราล้านนา) เพื่อช่วยให้มัคนายกและทางวัดไม่เผลอจองงานศพหรือทำพิธีเผาศพในวันต้องห้าม

### วิธีการคำนวณของระบบ:
ระบบจะตรวจเช็กความเชื่อมโยงโดยอัตโนมัติ:
1.  แปลงวันที่ของปฏิทินสุริยคติสากลเป็น **เดือนจันทรคติล้านนา** (เร็วกว่าเดือนภาคกลาง 2 เดือน เช่น เดือน 12 ไทยภาคกลาง = เดือน 2 ล้านนา หรือเดือนยี่)
2.  คำนวณหาวันตามระบบ **ลูกวันล้านนา** (ไจ้, เป้า, ยี, เหม้า, สี, ใส้, สะง้า, เม็ด, สัน, เล้า, เส็ด, ไค้)
3.  ตรวจสอบตามตำราเก้ากองล้านนาโบราณ:
    *   **เดือน 1 (เกี๋ยง):** ห้ามวันเม็ด (แพะ)
    *   **เดือน 2 (ยี่):** ห้ามวันสะง้า (ม้า)
    *   **เดือน 3:** ห้ามวันใส้ (งูเล็ก)
    *   **เดือน 4:** ห้ามวันสี (งูใหญ่)
    *   **เดือน 5:** ห้ามวันเหม้า (กระต่าย)
    *   **เดือน 6:** ห้ามวันยี (เสือ)
    *   **เดือน 7:** ห้ามวันเป้า (วัว)
    *   **เดือน 8:** ห้ามวันไจ้ (หนู)
    *   **เดือน 9:** ห้ามวันไค้ (หมู)
    *   **เดือน 10:** ห้ามวันเส็ด (สุนัข)
    *   **เดือน 11:** ห้ามวันเล้า (ไก่)
    *   **เดือน 12:** ห้ามวันสัน (ลิง)

### สถานะความปลอดภัยและการปฏิเสธคำขอ (Validation Rules):
*   **เมื่อเพิ่ม/แก้ไขตารางงานนิมนต์:** หากระบบพบว่ามีคำหลัก เช่น *เผาศพ, ฌาปนกิจ, ปลงศพ, งานศพ, อภิธรรมศพ* อยู่ในชื่อตารางนิมนต์ในวันเก้ากอง ระบบจะขึ้นแจ้งเตือนผิดประเพณีล้านนา และปฏิเสธการจัดเก็บข้อมูล
*   **เมื่อจองศาลา:** หากมีชื่องานศพ หรือกิจกรรมประเภทศาลาเป็น `funeral` และมีการกำหนดวันสิ้นสุดการจอง (วันสิ้นสุดงานซึ่งโดยจารีตคือวันฌาปนกิจศพจริง) ตรงกับวันเก้ากอง ระบบจะล็อกสิทธิ์และขึ้นหน้าต่างแจ้งเตือนป้องกันการบันทึกการจอง เพื่อความสงบเรียบร้อยและความสบายใจของญาติโยมในชุมชน

## 🚀 บันทึกการอัปเดตและปรับประสิทธิภาพระบบล่าสุด (Recent Updates & Optimizations)

ระบบได้รับการปรับปรุงประสิทธิภาพสิทธิ์และขีดความสามารถการทำธุรกรรมครั้งใหญ่ ครอบคลุม:

### 1. การปรับปรุงความปลอดภัยและการแยกบัญชีการเงิน (Finance Isolation)
* **การคัดแยกสถิติกราฟแท่งหลัก**: ปรับปรุงให้หน้าแดชบอร์ดของผู้ดูแลระบบ (Admin Dashboard) คำนวณเฉพาะข้อมูลบัญชีเงินวัดส่วนกลางเท่านั้น โดยคัดกรองธุรกรรมที่มี `monk_id` (เงินส่วนตัวของพระสงฆ์) ออกจากสถิติแนวโน้มรายรับ-รายจ่ายรายเดือนย้อนหลัง 6 เดือน ป้องกันข้อมูลปะปน

### 2. การอนุมัติและปรับสิทธิ์ของบทบาท Member
* **ระบบฝากกระดูก**: อนุมัติสิทธิ์พิเศษให้ผู้ใช้งานระดับ `member` (พระลูกวัด/สามเณร) สามารถบันทึกทะเบียนฝากอัฐิใหม่และแก้ไขข้อมูลให้แก่ญาติโยมได้ทันที
* **ระบบครุภัณฑ์และยืมคืน**: อนุญาตให้ `member` สามารถลงทะเบียนทรัพย์สินครุภัณฑ์ใหม่ บันทึกรายการยืมของ และทำรายการรับของส่งคืนวัดได้ เพื่อรองรับภาระงานธุรการจริงภายในวัด

### 3. ระบบยืมคืนครุภัณฑ์และตัดสต็อกอัตโนมัติ (Deduction & Return Sync)
* **แก้ไขบั๊กตัดสต็อก**: แก้ไขจังหวะการคิวรีเช็คสถานะการยืมเดิมก่อนการเขียนทับลง DB ทำให้ระบบสต็อกคลังครุภัณฑ์บวกกลับและหักออก (`available_qty`) ได้ตรงตามความจริง 100% ทุกครั้งที่มีการบันทึกยืม/คืน
* **Self-Correcting Sync**: เพิ่มการคำนวณยอดคงเหลือในสต็อกโดยหักยอดจริงของสิ่งของที่ยังไม่ถูกคืน (Active Borrows) ป้องกันคลังคลาดเคลื่อนเมื่อมีการแก้ไขข้อมูลจำนวนทั้งหมด (Total Qty) ในคลัง

### 4. ระบบการค้นหาและฟิลเตอร์ขั้นสูง (Advanced Search & Filters)
* **ค้นหาตามสถานที่เก็บ**: เพิ่มความสามารถในการสืบค้นครุภัณฑ์จาก **"สถานที่จัดเก็บ / ห้องเก็บของ" (`location`)** ช่วยให้พระสงฆ์ค้นหาของนิมนต์จัดงานได้สะดวกรวดเร็ว
* **ตัวกรองหมวดหมู่แยกเฉพาะ (Category Dropdown)**: เพิ่มแถบเลือกหมวดหมู่สิ่งของถัดจากกล่องค้นหาหลัก กรองแบ่งประเภทเครื่องครัว เครื่องเสียง อุปกรณ์จัดงาน ฯลฯ ได้อย่างรวดเร็ว

### 5. ระบบขยายภาพครอบคลุมทั่วทั้งระบบ (Global Image Lightbox Preview)
* **Image Lightbox Component**: สร้างคอมโพเนนต์ขยายดูรูปขนาดใหญ่สีดำหลังเบลอมาตรฐาน
* **รองรับการซูมเอกสารและหลักฐาน**: รองรับการคลิกดูรูปภาพขยายของโปรไฟล์พระภิกษุ, รูปภาพครุภัณฑ์วัด, รูปถ่ายผู้วายชนม์ในทะเบียนศพ, รูปถ่ายสลิปใบเสร็จ และเอกสารใบมรณบัตร โดยหากเป็นเอกสารชนิด PDF ระบบจะสั่งเปิดหน้าต่างแสดงผลบนเบราว์เซอร์ให้โดยอัติโนมัติเพื่อความถูกต้องและปลอดภัย

### 6. การเพิ่มดัชนีประสิทธิภาพฐานข้อมูล (PostgreSQL Query Index Optimization)
* มีการปรับใช้ดัชนีคิวรีข้อมูล (Query Indexes) บนตารางสำคัญ เพื่อเร่งความเร็วในการโหลดข้อมูลจาก Supabase ที่มีเงื่อนไข `is_deleted = false` ดังนี้:
  * `idx_transactions_monk_deleted` บนตาราง `transactions(monk_id) WHERE is_deleted = false`
  * `idx_transactions_date_deleted` บนตาราง `transactions(date DESC) WHERE is_deleted = false`
  * `idx_borrow_records_item_deleted` บนตาราง `borrow_records(item_id) WHERE is_deleted = false`
  * `idx_borrow_records_status_deleted` บนตาราง `borrow_records(status) WHERE is_deleted = false`
  * `idx_inventory_deleted` บนตาราง `inventory(is_deleted)`
  * `idx_ashes_deleted` บนตาราง `ashes(is_deleted)`
